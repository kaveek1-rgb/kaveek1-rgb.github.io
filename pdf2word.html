คำสั่ง หนังสือเวียน หรือแบบฟอร์มจากหน่วยเหนือส่วนใหญ่ส่งมาเป็น PDF — พิมพ์ทับหรือแก้ไขไม่ได้ตรง ๆ ต้องนั่งพิมพ์ขึ้นใหม่ทั้งฉบับ กว่าจะครบทุกจุดก็เสียเวลาที่ควรอยู่กับงานสำคัญกว่า

พิมพ์เอกสารราชการขึ้นใหม่ทั้งฉบับ

ได้ไฟล์ PDF มาแล้วต้องเปิดพิมพ์ใหม่ทีละบรรทัดใน Word เพื่อจะแก้ไขหรือใช้ต่อ

เปิด PDF แล้วกดแปลง ได้ไฟล์ Word แก้ไขได้ทันที

สระลอย วรรณยุกต์หลุดตำแหน่ง ตัวเลขไทยกลายเป็นสัญลักษณ์แปลก ๆ ต้องมานั่งไล่แก้ทีละคำ

↓ เปลี่ยนเป็น

ตัวอักษรไทยครบทุกสระ วรรณยุกต์ ตัวเลขไทย

ทำอะไรได้

ความสามารถทั้งหมดในตัวโปรแกรม

ออกแบบมาสำหรับเอกสารราชการไทยโดยเฉพาะ ไม่ใช่โปรแกรมแปลงไฟล์ทั่วไปที่เอามาปรับใช้

✓

ตัวอักษรไทยไม่เพี้ยน

สระ วรรณยุกต์ ตัวเลขไทย ครบถ้วนทุกตัว แม้ไฟล์ต้นฉบับจะมีปัญหาฟอนต์ฝังผิดพลาด โปรแกรมตรวจจับและแก้ให้อัตโนมัติ

✓

รักษารูปภาพและตราครุฑ

โลโก้หน่วยงาน ตราครุฑ ลายเซ็นสแกน อยู่ตำแหน่งเดิมเหมือนต้นฉบับ

✓

ตัวหนา ตัวเอียง การจัดวาง

หัวเรื่องกึ่งกลาง ลายเซ็นชิดขวา ระยะเยื้องย่อหน้า คำนวณจากตำแหน่งจริงในไฟล์ PDF ให้อัตโนมัติ

✓

ขนาด A4 ตามระเบียบสารบรรณ

ตั้งกระดาษ A4 และระยะขอบ (ซ้าย 3 ซม. ขวา 2 ซม. บน 1.5 ซม. ล่าง 2 ซม.) ตามระเบียบสำนักนายกรัฐมนตรีว่าด้วยงานสารบรรณ ให้เป็นค่าเริ่มต้นทุกไฟล์

✓

รองรับไฟล์ภาพสแกน/ถ่ายรูป

PDF ที่เป็นภาพถ่ายเอกสารหรือสแกน ใช้ระบบอ่านตัวอักษรจากภาพ (OCR) ให้อัตโนมัติ ไม่ต้องเลือกโหมดเอง

✓

แปลงพร้อมกันได้หลายไฟล์

เลือกไฟล์ PDF ทีเดียวหลายไฟล์ กดแปลงครั้งเดียว ได้ไฟล์ Word ครบทุกไฟล์

✓

ไม่ต้องติดตั้ง Python

ไฟล์เดียว แตก zip แล้วดับเบิลคลิกใช้ได้เลย ไม่ต้องลงโปรแกรมเสริม ไม่ต้องขอสิทธิ์แอดมิน

✓

ไฟล์ไม่ออกจากเครื่อง

แปลงไฟล์ในคอมของคุณทั้งหมด ไม่มีการอัปโหลดเอกสารขึ้นอินเทอร์เน็ต เหมาะกับเอกสารราชการและสำนวนคดี

คำถาม

คำถามที่ถามกันบ่อย

ต้องติดตั้ง Python หรือโปรแกรมเสริมอะไรไหม

ไม่ต้อง แตกไฟล์ zip แล้วดับเบิลคลิกใช้ได้เลย ไม่ต้องลงโปรแกรมเสริม ไม่ต้องขอสิทธิ์แอดมิน

ใช้กับ PDF แบบไหนได้บ้าง

ได้ทั้งสองแบบในไฟล์เดียวกัน — ทั้งที่มีตัวอักษรจริงและที่เป็นภาพสแกน/ถ่ายรูป หน้าที่เป็นภาพจะใช้ระบบอ่านตัวอักษรจากภาพ (OCR) ให้อัตโนมัติ

แปลงแล้วตัวอักษรไทยเพี้ยนไหม

หน้าที่มีตัวอักษรจริงในไฟล์ต้นฉบับจะตรงกับต้นฉบับทุกตัวอักษร โปรแกรมตรวจสอบและแก้ปัญหาฟอนต์ฝังผิดพลาดที่พบได้ในเอกสารราชการบางไฟล์ให้อัตโนมัติ ส่วนหน้าที่เป็นภาพสแกนใช้ OCR ซึ่งอาจมีคลาดเคลื่อนเล็กน้อยตามความคมชัดของภาพต้นฉบับ — ควรตรวจทานทุกครั้งก่อนใช้งานจริง โดยเฉพาะเอกสารสำคัญ

ไฟล์เอกสารถูกส่งออกอินเทอร์เน็ตไหม

ไม่ ทุกไฟล์แปลงในคอมของคุณทั้งหมด ไม่มีการอัปโหลดขึ้นเซิร์ฟเวอร์ใด ๆ ต่อเน็ตเฉพาะตอนดาวน์โหลดโปรแกรมครั้งแรก และตอนใช้ระบบอ่านตัวอักษรจากภาพ (OCR) ครั้งแรกเท่านั้น

แปลงพร้อมกันหลายไฟล์ได้ไหม

ได้ กดเลือกไฟล์ PDF ได้ครั้งละหลายไฟล์ แล้วกดแปลงครั้งเดียว โปรแกรมจะแปลงให้ครบทุกไฟล์ตามลำดับ

ไฟล์ Word ที่ได้ ขนาดกระดาษเป็นอะไร

ตั้งเป็น A4 พร้อมระยะขอบตามระเบียบสำนักนายกรัฐมนตรีว่าด้วยงานสารบรรณเป็นค่าเริ่มต้น (ซ้าย 3 ซม. ขวา 2 ซม. บน 1.5 ซม. ล่าง 2 ซม.) เหมาะกับการแปลงหนังสือราชการโดยเฉพาะ

ฟรีจริงไหม มีวันหมดอายุไหม

ฟรีจริง ไม่มีวันหมดอายุ ไม่ต้องลงทะเบียน การสนับสนุนผ่านพร้อมเพย์เป็นความสมัครใจล้วน ๆ ไม่ใช่ค่าลิขสิทธิ์หรือเงื่อนไขการใช้งาน
